# zapret2-youtube-discord

Альтернатива Flowseal для обхода блокировок YouTube и Discord на движке Zapret2.

## 📦 Что это?
Этот проект — замена устаревшему Flowseal (Zapret1). Он использует **Zapret2** от bol-van, который активно развивается и поддерживает современные методы обхода DPI.

## 🚀 Быстрый старт
1. Скачайте [последний релиз](ссылка на релиз).
2. Распакуйте в любую папку.
3. Запустите `general.bat` **от имени администратора**.
4. Готово! YouTube и Discord должны открываться.

## 📂 Структура
- `general.bat` — основной скрипт запуска
- `bin/` — winws2.exe и библиотеки
- `lists/` — списки доменов и IP
- `bins/` — бинарные файлы для подмены

## 🔧 Настройка
Вы можете редактировать `general.bat` или списки в `lists/`, чтобы адаптировать под своего провайдера.
